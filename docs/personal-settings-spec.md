# Персональные настройки

## Согласованный контракт

В окне «Настройки профиля» остаются фото, часовой пояс, уникальный ник, имя и email. Кнопка «Дополнительные настройки» открывает защищённую страницу `/profile/settings`. Вид приложения, персональные инструменты и уведомления разделены по категориям. Дополнительные инструменты коллекции можно включать независимо. Выбран второй вариант входа в подбор: плавающая кнопка рядом с быстрым вводом.

Значения по умолчанию для существующих и новых аккаунтов:

- `quickAddEnabled`: true — быстрый ввод.
- `watchTonightEnabled`: false — «Что посмотреть сегодня».
- `collectionFilesEnabled`: false — импорт и экспорт.
- `notifyNewMessages`: true — новые сообщения.
- `notifyFriendRequests`: true — запросы в друзья.
- `notifyRecommendations`: false — рекомендации от друзей.
- `showAchievements`: true — блок достижений в своём профиле.
- `showDetailedAnalytics`: true — подробная аналитика в своём профиле.
- `showCommunityTops`: true — пункт «Топ» в основном и мобильном меню.
- `showActorsSection`: true — отдельная вкладка «Актёры» в медиатеке.

Все десять значений хранятся в профиле на backend. Переключатель отправляет только изменяемое поле через существующий `PATCH /users/:id`. Сохраняются только boolean, null/строки/числа отклоняются. Изменять профиль может его владелец или администратор. Обычное обновление имени, аватара или часового пояса не сбрасывает переключатели.

При входе профиль читается через `GET /auth/@me`. Выбор переносится между устройствами после входа или обновления профиля. Независимые старые ключи уведомлений в localStorage больше не являются источником настроек и автоматически не присваиваются текущему аккаунту. Существующий кеш профиля не заменяет серверную проверку сессии.

Переключатели сохраняются сразу. Пока запрос выполняется, другое сохранение профиля заблокировано. При ошибке остаётся прежнее значение и появляется сообщение с возможностью повторить действие. Поздний ответ прежней сессии не заменяет профиль нового аккаунта.

## Отображение

- Выключенный инструмент не оставляет кнопку или пустой плавающий контейнер. Быстрый ввод и подбор работают независимо.
- При выключении инструмента его открытое окно или панель закрывается. Скрытие импорта/экспорта не меняет доступность обычного добавления тайтла.
- Настройки интерфейса не являются проверкой прав. Защита API сохраняется независимо от видимости кнопок.
- На мобильном экране плавающие действия находятся выше нижней навигации. Кнопка настроек профиля остаётся справа сверху: до 640 px это шестерёнка 44×44, выше — кнопка с текстом.
- Онбординг объясняет дополнительные инструменты и открывает реальную категорию страницы настроек через `?section=personal` или `?section=notifications`. Он не включает инструменты автоматически и не подсвечивает скрытый быстрый ввод.

## Миграция и проверки

Миграция `20261016010000_user_preferences` добавляет шесть колонок в users с указанными defaults. Существующие записи сохраняются. Старый код совместим с добавленными колонками, удалять их для отката интерфейса не требуется.

Проверяются defaults, сохранение и повторное чтение, независимость аккаунтов, чужой профиль, строгая валидация, ошибка и повтор сохранения, поздний ответ после смены сессии, запрет параллельных сохранений, видимость инструментов, desktop/mobile и переходы онбординга. Флаг рекомендаций сохраняется, но самостоятельная функция рекомендаций от друзей пока не реализована.

## Вид приложения: согласованный вариант B, task-51

На странице дополнительных настроек используется согласованная раскладка B по образцу центра уведомлений: категории слева и выбранный блок справа. На телефоне категории находятся сверху. Выбранная категория сохраняется в адресе страницы, неизвестная категория открывает «Вид приложения».

«Вид приложения» содержит компактные карточки с пояснением, управляющим элементом и схематическим предпросмотром. Предпросмотр использует фактическое сохранённое значение. При отказе сервера прежнее значение и соответствующий предпросмотр сохраняются, у карточки есть сообщение и повтор. Значения между аккаунтами не переносятся. Выключение не удаляет данные и не меняет приватность профиля.

Смена категории использует то же появление, что история уведомлений: opacity от 0 до 1 за 180 мс, ease-out. Первое открытие и повторное нажатие на выбранную категорию не анимируются. Предпросмотры плавно исчезают и освобождают место за 160–200 мс. `prefers-reduced-motion` отключает обе анимации.

1. **Достижения** — переключатель скрывает весь блок достижений в своём профиле, без пустого места. Награды сохраняются.
2. **Подробная аналитика** — выбор «Основная / Подробная» скрывает только карточку персональной аналитики. Основные счётчики коллекции остаются в любом режиме. В API передаётся boolean `showDetailedAnalytics`.
3. **Топы сообщества** — переключатель скрывает пункт «Топ» в обоих меню, не отключая участие пользователя в рейтингах и не запрещая прямые ссылки.
4. **Раздел «Актёры»** — переключатель скрывает отдельную вкладку медиатеки, сохраняя актёрский состав произведений и переходы по актёрам из карточек. Прямые ссылки не блокируются.

Все четыре новых значения по умолчанию true для старых и новых аккаунтов. Миграция только добавляет колонки, без сброса существующих настроек. Поиск, основные фильтры, обычное добавление, статусы и оценки остаются основой интерфейса. Стиль использует токены проекта, текст 17/24 и 14/20, touch targets не меньше 44px. Проверяются мобильные ширины 320/390, desktop, обе темы, сохранение/перезагрузка и ошибка/повтор.
