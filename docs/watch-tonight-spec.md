# Что посмотреть сегодня и обложки без постера

Исходный этап согласован пользователем 16 октября 2026 по интерактивному макету. Порядок: спецификация → black-box тесты → код → desktop/mobile/семь тем. Он выполнялся без новых зависимостей и миграций. Позднее пользователь выбрал плавающий вход и серверные [персональные настройки](personal-settings-spec.md). Исторические checkpoint ниже не отменяют этот актуальный контракт. Без commit/push.

## Подбор

- Вход: плавающая кнопка «Что посмотреть?» рядом с быстрым вводом в «Моей коллекции». На телефоне подпись «Подбор». Кнопка доступна при любом фильтре коллекции, если включена в профиле. Баннер под фильтрами и вариант рядом с «Буду смотреть» отменены.
- По умолчанию подбор скрыт. Его включает переключатель «Что посмотреть сегодня» в «Профиль → Настройки → Персональные настройки». Выбор хранится на backend отдельно для каждого аккаунта. Выключение закрывает открытое окно подбора.
- Источник: вся собственная коллекция, seeLater=true и watchStatus=NOT_STARTED. Смотрю/просмотрено/брошено исключены. Поиск, фильтры и загруженная страница коллекции не ограничивают подбор.
- Использовать существующий защищённый GET /users/:id/movies/page, последовательно загрузить страницы по 100. Не менять общий store/фильтры. Проверять форму ответа, owner, уникальность ID и согласованность total. При изменении total, дублях или неполных страницах показать ошибку и повтор. Это не атомарный снимок БД между несколькими GET.
- Окно BaseModal form на desktop, стандартный нижний лист на mobile. Фильтры: любой тип/фильм/сериал/аниме/мультфильм/ТВ-шоу и любой жанр/жанры приложения. Старые null/GENERAL типы считаются фильмом или сериалом по isSerial.
- Один случайный кандидат. «Другой вариант» не повторяет уже показанное до исчерпания текущего набора. «Начать заново» явно сбрасывает цикл. Изменение фильтров начинает новый цикл.
- Один кандидат: кнопка другого варианта недоступна, причина видна. Пустой исходный список: объяснение и «Открыть каталог». Ноль по фильтрам: фильтры остаются и «Сбросить фильтры». Ошибка: «Повторить». Загрузка: понятный статус, повторные действия заблокированы.
- «Открыть карточку» закрывает окно и открывает обычный /detail/:id. Подбор/повтор/открытие не пишут статусы, прогресс или оценки. Никаких отзывов и спойлеров в карточке подбора.
- Закрытие, logout/смена пользователя, unmount отменяют запрос и сбрасывают кандидатов. Поздний ответ не показывает старые данные. Повторное открытие загружает актуальный список.

## Постер по умолчанию

- Если постер отсутствует или не загрузился, показывать локальную SVG-иллюстрацию вместо внешнего No Image. Загруженный/внешний постер в приоритете.
- Десять сюжетов в едином плоском геометрическом стиле: горы, море/маяк, город, дюны, космос, лес, арка, река, облака/луна, геометрическая композиция. Несколько согласованных оттенков в каждой теме.
- Вариант определяется стабильным hash идентификатора карточки, палитра учитывает тему. Без Math.random при каждом render, сетевых запросов, генеративного API и хранения файлов в БД/S3. Старые карточки получают fallback только при отображении.
- Название/краткая подпись расположены поверх нижней непрозрачной полосы, с ограничением строк. На маленьких миниатюрах иллюстрация без подписи. Пользовательский текст выводится как текст Vue, не вставляется в SVG/HTML.
- Общий компонент для коллекции, каталога, избранного, деталей/preview, оценки, списков, рейтинга, кандидатов дублей, карточек чата и формы создания. Не затрагивать фотографии актёров и аватары.
- Постер в форме создания становится необязательным, API уже допускает отсутствие. Не отправлять пустой imageUrl или URL сгенерированного SVG в API. Предпросмотр показывает fallback. Ошибки обязательных названия/типа/страны/жанра/описания сохраняются. Upload/media ownership/cleanup не менять.
- PDF при отсутствии/ошибке постера использует те же иллюстрации как встроенный вектор. Это не меняет JSON/CSV или записи БД. Без постеров PDF остаётся текстовым.

## Приёмка

- Black-box UI с настоящим шаблоном и границей HTTP: все страницы, отсутствие посторонних статусов, пять типов/жанры, отсутствие повторов/явный restart, empty/one/error/retry, отмена и смена аккаунта, переход по правильному ID и отсутствие запросов записи.
- Постеры: сохранённая картинка в приоритете, error→fallback, новая src после ошибки восстанавливается, десять вариантов и стабильность, все темы, текст не исполняется как markup. Реальная форма создаётся без постера и сохраняет остальные проверки. Реальный PDF встраивает fallback-иллюстрации.
- Desktop 1440/1024, mobile 390/320, граница 768. Все семь тем. Проверить кнопку входа вместе с навигацией/поиском, окно/нижний лист, длинные названия, селекты, footer, Escape/focus, отсутствие горизонтального переполнения. Рабочие пользовательские записи не менять для QA.
