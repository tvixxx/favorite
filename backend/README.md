# FavouriteApp API

NestJS 11, Prisma 7.3, PostgreSQL 18 и Socket.IO. Требуются Node 22 и Yarn Classic 1.22.22. Зависимости закреплены в `yarn.lock`, проект использует публичный npm registry.

## Локальный запуск

Настройте локальную PostgreSQL и приватный `.env` по [инструкции проекта](../README.md). Затем из `backend`:

```bash
yarn install --frozen-lockfile
yarn prisma generate
yarn prisma migrate deploy
yarn start:dev
```

API: `http://localhost:3005`, Swagger: `/docs`. `GET /health` проверяет готовность базы. Не применять `migrate reset` или `db push` к базе с пользовательскими данными. При расхождении истории сначала проверить фактическую схему и SQL.

## Проверки

```bash
yarn lint:check
yarn test --runInBand
yarn build
yarn audit --groups dependencies
yarn audit
```

Полный аудит включает инструменты тестирования и Prisma CLI. Его результат отличается от production-аудита. CLI запускается отдельным контейнером миграций, в runtime API его нет.

## Согласованные правила

- Имя: 3–50 символов после обрезки пробелов.
- Сериал: до 1000 сезонов и 10000 эпизодов.
- Один отзыв пользователя на фильм, с редактированием и удалением автором. Одновременные создания сериализуются по паре пользователь/фильм, уникальный индекс дополнительно защищает БД.
- Смена сериала на фильм запрещена, если хотя бы у одного пользователя есть положительный прогресс сезона или эпизода. Без прогресса смена очищает только количество сезонов/эпизодов в каталоге.
- Общий каталог редактирует администратор. Пользователь редактирует созданные им записи. Личная коллекция принадлежит пользователю.

Миграция единственного отзыва не удаляет дубли автоматически. Если они есть, сначала выбрать сохраняемый отзыв вручную.
